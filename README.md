# pbvsi-bogor-ku2012
validasi data Pengkot PBVSI BOGOR

Aplikasi ini sudah dipublikasikan sebagai GitHub Pages publik.

- Halaman aplikasi: https://biddatapbvsi2-glitch.github.io/pbvsi-bogor-ku2012/

Cara pakai:
1. Buka link aplikasi.
2. Paste daftar nama master PBVSI di kotak kiri.
3. Paste daftar nama + tanggal lahir pendaftar di kotak kanan.
4. Tekan tombol "Mulai Verifikasi & Cocokkan Data".
